Workforce Security Operations Runbook

High Workforce API Request Volume

Investigation and containment procedure for unusual request-volume activity affecting the Workforce Security API.

Severity: High Service: workforce-security-api Environment: dev Category: API abuse

Alert condition

Grafana fires this alert when the Workforce Security API receives more than 10 application requests during the configured detection window.

Health checks and Prometheus scrapes are excluded from the alert query.

Elevated volume is not automatically malicious. Validate whether the activity is expected before containment.

1 Validate

  1. Open the Workforce Security Operations dashboard.
  2. Confirm the alert is currently firing.
  3. Review request volume and affected routes.
  4. Check whether a load test or maintenance activity was scheduled.
  5. Confirm whether the affected integration is recognized.

2 Investigate

Review the following evidence:

  • Organization ID
  • Integration ID
  • Source IP address
  • Request count and normal baseline
  • HTTP status codes
  • Affected API routes
  • Related audit entries

3 Analyst response

  1. Review /security/v1/events.
  2. Locate the high-volume security event.
  3. Change its status from Open to Investigating.
  4. Record the organization, integration, source IP, and request count.
  5. Escalate to a Security Admin if containment is required.

4 Admin containment

  1. Confirm containment is justified.
  2. Revoke the affected integration's API key.
  3. Confirm the security event changes to Contained.
  4. Coordinate replacement credentials with the integration owner.

5 Verify recovery

  • The revoked API key returns API_KEY_REVOKED.
  • Request volume returns to baseline.
  • The Grafana alert resolves.
  • The event remains marked Contained.
  • No unexpected follow-on activity appears.

Audit evidence

Confirm that /security/v1/audit contains:

  • SECURITY_EVENT_INVESTIGATION_STARTED
  • API_KEY_REVOKED

End-to-end response flow

Grafana alert → Discord notification → Validate activity → Investigate event → Admin containment → Verify resolution
